Projeto GCS - Versão Principal

Página de exemplo para praticar Git e GitHub em equipe.

Sobre o projeto

Este projeto simula o trabalho de uma equipe de desenvolvimento usando controle de versão com Git e GitHub, aplicando os conceitos de Gerência de Configuração de Software (GCS).

Objetivos

  • Controle de versão dos artefatos do projeto
  • Criação e merge de branches
  • Resolução de conflitos
  • Convenções de commit e de versionamento

Fluxo de trabalho

  1. 1. Criar branch
  2. 2. Fazer commits
  3. 3. Abrir Pull Request
  4. 4. Revisão e aprovação
  5. 5. Merge
  6. 6. Tag de versão

Mensagens de commit seguem o padrão tipo: descrição, por exemplo feat: adiciona rodapé.
